# QuantumForge: бот по базе знаний

Консольный RAG-бот с русскими вопросами и ответами по 30 статьям о вымышленной вселенной. Локальные модели, поиск FAISS, Python 3.11. Отчёт — [Project_template.md](Project_template.md).

## Запуск через Docker

На подготовленном компьютере образ и модели уже находятся локально. Из папки проекта:

```powershell
docker compose run --rm bot
```

После приглашения `>` задайте вопрос:

```text
На каком языке говорит Брумак?
```

Для завершения введите `выход`. Один вопрос без интерактивного диалога:

В Linux-контейнере для редактирования строки подключается стандартный модуль `readline`: исправление русской буквы через Backspace сохраняет целый символ UTF-8. Если поступила повреждённая строка, бот просит повторить вопрос и продолжает работу.

```powershell
docker compose run --rm -T bot python bot.py --question "На каком языке говорит Брумак?"
```

Программа печатает русский ответ и источники. Для технической диагностики добавьте `--json`.

Контейнер ограничен 4 CPU и 12 ГБ памяти. FAISS работает внутри процесса, отдельный сервер не требуется. Сеть при ответах отключена, модели подключены только для чтения.

## Установка на другом компьютере

Нужны Docker либо Python 3.11, около 16 ГБ RAM, место для зависимостей и весов. Первое скачивание моделей требует интернета; генерация выполняется локально. Файлы моделей не входят в Git и архив проекта.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python download_models.py
docker compose build
docker compose run --rm bot
```

Для запуска без Docker после скачивания выполните `python bot.py`. На Linux окружение активируется через `source .venv/bin/activate`.

При корпоративном TLS-прокси для сборки можно передать доверенные публичные сертификаты через BuildKit secrets `build_ca` и `build_ca_extra`; сертификаты не сохраняются в образе.

## Подготовка базы и индекса

```text
python prepare_knowledge.py
python build_index.py --include-attack
```

В `raw_pages/` сохранены 32 исходные HTML-страницы и русские текстовые копии рядом с ними: `01.html` и `01.txt`, `02.html` и `02.txt` и так далее. Работа с текстом начинается с русских `.txt`. Скрипт `download_pages.py` сохраняет HTML и не перезаписывает подготовленные текстовые копии.

В `source_fragments.json` записаны файл источника и границы выбранного описания (`start`, `end`, в символах). `prepare_knowledge.py` читает этот участок из соответствующего `.txt`, заменяет имена и названия по `terms_map.json` и записывает результат в `knowledge_base/`. Словарь учитывает падежи и сочетания слов. Для базы выбраны описания 30 сущностей; полные исходники не индексируются.

При редактировании текстовой копии проверьте границы выбранного фрагмента в `source_fragments.json`, затем повторите подготовку базы и индекса. Ссылки на статьи находятся в `sources.json`.

Эмбеддер — `intfloat/multilingual-e5-small`: 384 измерения, предел 512 токенов. Он использует служебные префиксы `query: ` для вопросов и `passage: ` для документов. Версия закреплена в `settings.py`. При смене модели индекс нужно пересоздать.

В базе 30 русских статей по 109–126 слов. Все статьи помещаются в ограничение модели и сохраняются целиком. С тестовым документом инъекции — 31 вектор. Статистика находится в `index/statistics.json`, фрагменты и их позиции — в `index/chunks.json`.

Для индекса без тестового документа выполните `python build_index.py`.

## Проверка

```powershell
docker compose run --rm -T bot python evaluate.py
```

Программа печатает по-русски вопросы, ответы, состояние защиты и причины результатов. Она выполняет десять основных проверок, два повтора атаки без защиты и одну отдельную проверку фильтра документа. Для построчного JSON добавьте `--json`.

В Windows PowerShell перед передачей вывода Docker в конвейер установите UTF-8 в текущем окне:

```powershell
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
```

Сохранённые результаты — в `results/`, десять снимков — в `screenshots/`. Строка `swordfish` является учебным примером. Исходная команда атаки из задания сохранена дословно внутри тестового документа.

Маленькая модель может ошибаться на сложных вопросах. Фильтры распознают явные варианты инъекции, но не обеспечивают защиту от всех формулировок.

Подготовлены русские текстовые копии без разметки и сносок. В выбранных описаниях убраны сведения о производстве и уточнены местоимения; для базы заменены имена и названия по `terms_map.json`. Лицензия распространяется на русские тексты и их обработку.
